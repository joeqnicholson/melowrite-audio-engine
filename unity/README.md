# Melowrite Audio Engine for Unity

1. Extract the ZIP to a folder outside your Unity project.
2. In Unity, open **Window > Package Manager**.
3. Choose **+ > Add package from disk** and select the extracted `package.json` file.
4. In Melowrite, use **Export Project** to export your `.melo` project to a folder inside your Unity project's `Assets` folder.
5. Add a **MeloSource** component to a GameObject, drag the `.melo` file into the **Song** slot, and enable **Play On Awake**.
