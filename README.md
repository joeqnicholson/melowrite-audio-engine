# Melowrite Audio Engine

Play Melowrite projects in Unity, C#, or C/C++ games on Windows x64.

[Download](https://github.com/joeqnicholson/melowrite-audio-engine/releases/latest) the Unity, C#, or C/C++ ZIP and follow its README.

Unity can also install from this Git URL:
`https://github.com/joeqnicholson/melowrite-audio-engine.git?path=/unity`

Demo assets have separate terms in `unity/Licenses/`.
