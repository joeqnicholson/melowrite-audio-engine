Melowrite runtime version 0.1.17 for Windows x64.

- Melowrite-Cpp-win64.zip: C/C++ API and C console playback example.
- Melowrite-CSharp-win64.zip: C# API, audio adapters, and MonoGame example.
- Melowrite-Unity.zip: Unity package with the Adaptive Music Demo.
- Melowrite-Godot.zip: Godot addon with the Melowrite Platformer example.

Setup instructions and licenses are included in each package.
